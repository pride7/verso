Six capabilities

围绕 Markdown 与文件构建完整工作流。

Verso 不会把笔记转换为专有数据。编辑、组织、检索与协作均直接建立在 Markdown、文件夹和 Git 之上。

01 · Markdown first

日常编辑与长期保存可以兼得。

整个笔记库就是一个普通文件夹。使用同名文件夹组织子文档时，界面会将 X.md 与 X/ 视为同一节点，使内容与相关资料保持在一起。

  • 不自动补写你没有要求的 id、title 或时间字段。
  • 搜索、标签与反向链接来自可随时重建的本地索引。
  • 数据库视图保存在笔记代码块中；编辑单元格即编辑对应的 frontmatter。

02 · Math input

公式输入不应中断写作。

Verso 将公式输入视为核心能力，而非 Markdown 的附加功能。触发词仅在数学环境中生效，即使公式尚未闭合也可立即使用。

  • // 生成分式，@a 生成 \alpha，pmat3x3 生成矩阵骨架。
  • Tab 在待填位置之间跳转；填写完成后继续跳出括号。
  • 桌面有符号搜索，手机有专属公式工具条，不把两种输入方式混为一谈。

05 · Project center

先从项目中心掌握全局，再进入单个项目处理细节。

项目中心按状态汇总仓库中的全部项目，并提供检索与筛选。进入项目后，项目总览仅呈现当前结论、下一步和阻碍；完整过程仍保留在可独立阅读的记录中。

  • 项目卡片汇总状态、更新时间和待处理事项，点击即可进入对应总览。
  • 项目总览固定展示当前结论、状态、下一步、阻碍和最近进展。
  • 实验、问题、决策和资料各自是一篇普通 Markdown 子文档。
  • 可随时从项目中心或文档树打开原文，不会形成封闭的项目数据。

04 · Mind map

切换视图，不复制内容。

思维导图由笔记标题与列表即时生成。节点对应正文中的原始行，因此在图上编辑、增加分支或删除子树，始终是在编辑同一篇 Markdown。

  • 不保存额外坐标，不会往笔记里塞一份其他软件看不懂的数据。
  • Enter 添加同级，Tab 添加子级，Space 折叠。
  • 键盘、鼠标与触摸设备都有对应操作方式。

03 · Sync & collaboration

协作聚焦内容，无需面对 Git 命令。

Verso 使用 Git 作为同步与版本历史的底层机制，同时将分支、暂存区等概念留在后台。日常只需同步；需要回溯时，仍可查看完整且可验证的历史。

  • 停手后自动记录版本，提交说明会指出具体修改的笔记。
  • 共享一篇笔记可创建独立空间，不必交出整个私有库。
  • 多人修改时显示“谁改了什么”；真正冲突才进入按段落或属性处理的面板。

06 · Your AI, your tools

让 AI 服务于笔记工作流，而非取代它。

Verso 不替用户选择模型，也不将内容发送至内置服务。它提供与笔记库相连的终端，使你能够使用已信任的 AI CLI 处理纯文本文件。

  • 可一键把当前笔记或选区作为上下文插入终端，不会自动执行命令。
  • AI 修改后可直接查看逐行差异；不满意就恢复，不会丢掉原稿。
  • 笔记库会带一份 AI 可读的约定说明，降低误改目录和视图定义的风险。
