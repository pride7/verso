# Verso · 页

一个本地优先的 Markdown 笔记软件：写公式要快，整理内容要清楚，数据始终留在自己手里。

你的笔记库就是硬盘上的普通 `.md` 文件。即使不再使用 Verso，用记事本、Obsidian 或
任意编辑器也能直接打开；Verso 负责把这些文件变成好写、好读、好管理的笔记库，而不是把
内容关进专有格式。

桌面与移动端共用 Tauri 2、Rust、React 和 CodeMirror 6。安装包约 10 MB，内存占用约为
同类 Electron 应用的一半。

当前版本：**v0.7.22**。完整设计见 [DESIGN.md](DESIGN.md)，每次更新见
[CHANGELOG.md](CHANGELOG.md)。

## 为什么是 Verso

### 纯 Markdown，始终可迁移

整个笔记库就是一个普通文件夹。子文档通过同名文件夹组织：`X.md` 和 `X/` 在界面中合并
为同一个节点，内容与子文档自然归在一起。

```
界面中的结构                 磁盘上的文件
▼ 数学                       数学/
  ▼ 线性代数                 ├── 线性代数.md
      特征值                 ├── 线性代数/
    ▼ 奇异值分解             │   ├── 特征值.md
        计算方法             │   └── 奇异值分解.md
    泛函分析                 └── 泛函分析.md
```

- 不会自动补写 `id`、`title`、`created` 等字段；删掉 frontmatter 就是真的删掉。
- 写入采用原子替换：`.tmp` → fsync → rename，断电也不会留下半份文件。
- 搜索、标签和反向链接依赖 SQLite 索引，但它只是可重建的派生数据；删除 `.verso/`
  不会丢任何笔记。500 篇笔记建索引少于 1 秒，中文两个字也能搜索。
- database 视图也是 Markdown 中的 `verso-view` 代码块。改表格单元格就是改对应笔记的
  frontmatter；看板拖动卡片就是改它的 `status`。

### 为公式而生的输入体验

目标很简单：写一页手写公式，不应比在纸上慢。

- 内置 135 条触发词，并兼容 Obsidian Latex Suite 配置：`//` 输入分式、`@a` 输入
  `\alpha`、`xsr` 输入 `x^{2}`、`pmat3x3` 生成 3×3 矩阵骨架。
- 触发词在最后一个字符输入后自动展开；`Tab` 依次跳到待填位置，完成后自动跳出括号。
- 规则只在公式中生效，连刚输入 `$`、公式尚未闭合时也可用；英文触发词带词边界，不会
  把 `point` 或 `print` 误展开。
- 光标进入公式后会显示实时预览。`Ctrl+/` 打开符号面板，按“积分”“叉乘”“属于”等名称即可查找。
- 手机端提供独立的公式工具条，按公式模式、希腊字母和算符分组，而不是勉强照搬桌面的
  Tab 交互。

### Git 同步与异步协作

笔记库可以直接是 Git 仓库，但日常界面不要求理解分支或暂存区：只需看到同步状态，按一次
“同步”。仓库、权限和远端都由你自己掌握，Verso 不保存你的内容，也不自建协作服务器。

- 停手五分钟自动记一版，提交说明会写清具体改了哪篇笔记；没有改动时不产生空提交。
- 可查看完整历史，也可只把某一篇笔记恢复到某个版本；恢复前会先保存当前状态，因此恢复
  本身也可撤回。
- 协作动态按“谁改了什么”呈现，而不是暴露 Git 命令。上次同步后尚未阅读的变化会被突出显示。
- 加入共享仓库只需填写远端地址、令牌、署名和本地位置；双方已有内容时会先预检，绝不静默覆盖。
- 分享一篇笔记不会暴露整个库：Verso 会创建一个独立共享空间，其中只包含该笔记、它的
  子文档和附件；同一组协作者可持续复用该空间。
- 协作者可以先提交“修改建议”，再由其他成员逐文件接受或退回。真正冲突时才进入三方对比，
  可按属性或段落定稿。

同步使用 HTTPS 与令牌；令牌保存到系统钥匙串，Android 保存到应用私有目录，且不会经过前端。

### 同一篇笔记的思维导图

思维导图不是另一份文件，而是当前笔记的另一种编辑视图。节点对应正文中的标题或列表项，
布局即时计算，不额外保存坐标；所以把 `.md` 放到其他软件中，内容不会缺失，也不会多出
一堆导图数据。

- 在图上改文字、添加同级或子级、删除子树，实际修改的仍是 Markdown，因此撤销、自动保存
  与外部改动检测都照常工作。
- 快捷键沿用常见导图习惯：`Enter` 添加同级，`Tab` 添加子级，`F2` 编辑，`Space` 折叠。
  所有操作都有鼠标入口；触摸设备则使用节点末尾的 `⋯` 菜单。
- 标题与列表会一起形成导图：正式结构和随手记下的要点都能看见。

### 项目中心：只看现在最重要的事

项目笔记最容易越写越长，最后反而找不到当前结论。Verso 把“项目总览”和“完整记录”分开：
总览只回答现在怎样，过程则沉到普通子文档中。

- 给笔记设为 `type: project` 后，打开时默认进入项目总览：当前状态、一句结论、最多三项
  下一步、阻碍与最近三条进展都在一屏内。项目做得再久，主页也不会无限变长。
- 进展、实验、问题、决策、资料分别保存为普通 Markdown 子文档，可随时在文档树中打开、
  移动或编辑。
- 一条进展就是普通标题，例如 `## 2026-08-05 14:20`，新记录插在最前面；它可以折叠、
  出现在大纲中，也能进入思维导图。
- 项目中心提供仓库级总览，可按状态或关键词查找所有项目（`Mod+Alt+J`）。
- 进展可快速记下一句话；实验、问题等需要公式、图片、代码或表格的内容，则先填标题和摘要，
  随后直接进入完整编辑器。

### 把 AI 工具放在笔记旁边

Verso 不绑定模型，也不提供“AI 续写”按钮；它提供的是一条可靠路径，让你使用已有的 AI CLI。

- 编辑器下方或右侧有可折叠终端（``Ctrl+` ``），默认工作目录就是当前笔记库。
- 纯文本笔记可直接交给 Claude Code、Codex、aider 等工具处理：整理结构、生成索引、修链接、
  合并散记、翻译或生成 database 查询都不需要导出。
- 一个快捷键可把当前笔记或选区作为 `@相对路径` 插入终端；它只提供上下文，不会自动执行命令。
- Git 负责兜底：运行前后都能逐文件查看改动，不满意即可恢复。
- 打开笔记库时会生成一份给 AI 阅读的仓库说明，减少它误改文件结构的风险。

## 下载

安装包发布在 **[GitHub Releases](https://github.com/pride7/verso/releases/latest)**，
每次推 tag 由 CI 构建上传，发布页附有「安装包选择」对照表。桌面端装好后可以在应用内
检查更新，不必再回来手动下载。

| 平台 | 推荐安装包 |
|---|---|
| Windows 10 / 11 | `Verso_<版本>_x64-setup.exe`（另有 MSI，供需要 MSI 部署的环境） |
| macOS（Apple Silicon） | `Verso_<版本>_aarch64.dmg` |
| macOS（Intel） | `Verso_<版本>_x64.dmg` |
| Android（arm64） | `Verso_<版本>_arm64.apk` |
| Linux（Debian / Ubuntu / Fedora / 其他） | `.deb` / `.rpm` / `.AppImage`（v1 暂不声明支持） |
| iOS | 尚未打包，需自行从源码构建 |

发布页里的 `.sig` 与 `latest.json` 由自动更新机制使用，不需要手动下载。

> macOS 安装包尚未完成 Apple 签名与公证，首次启动时 Gatekeeper 可能提示「已损坏，无法
> 打开」。安装后在终端执行 `xattr -cr /Applications/Verso.app` 即可，只需一次，
> 不影响后续应用内更新。

## 从源码运行

```bash
cd verso
pnpm install
pnpm tauri dev
```

提交前请运行：

```bash
cd verso/src-tauri && cargo test   # Rust：树合并、frontmatter、重命名事务、路径越界
cd verso
pnpm exec tsc --noEmit             # 前端类型检查
pnpm test                          # Node：解析器、模糊匹配、snippet 匹配
pnpm test:browser                  # 真实 Chromium：补全、实时预览、database 视图
```

> 不要使用 `cargo check`：这台开发机的 Smart App Control 会拦截它新生成的构建脚本。
> 其他工具链说明见 [AGENTS.md](AGENTS.md)。

## 名字的由来

*Verso* 是书籍学中“一页纸的背面”，也就是翻开一本书时左手边的那一页；正面叫
*recto*。它来自拉丁语 *verso folio*，意为“翻过这一页”。中文名为“页”。
